# Gestión de Proyectos (ADMI_5077) · Sílabo interactivo · UTPL

Sitio estático del curso: cronograma de las 16 semanas, lecturas con su tipo de acceso, contacto y tutorías, y una lista personal de tareas. Sin datos de estudiantes, sin cuentas, sin servidor.

## Archivos

```
index.html            página: lo próximo, buscar lectura, contacto, cronograma, tareas, evaluación, políticas
css/estilo.css        diseño (no se edita durante el semestre)
js/app.js             lógica mínima (no se edita durante el semestre)
datos/silabo.js       ÚNICA fuente de contenido: fechas, actividades, recursos, evaluación, políticas
img/logo_UTPL.jpg     logo institucional
revision_silabo.md    paso 3: comparación con el plan docente y discrepancias abiertas
pruebas.md            paso 4: resultados de pruebas
```

## Probar en su computadora

Abra `index.html` con doble clic. Para ver cómo se verá otro día: `index.html?hoy=2026-11-25T10:30`.

## Actualizar durante el semestre

1. Edite solo `datos/silabo.js` (fechas, enlaces, actividades).
2. Cambie `"version"` y `"actualizado"`.
3. Suba el archivo a GitHub; Pages republica en uno o dos minutos.

## Publicar en GitHub Pages (paso 5)

1. En GitHub: **New repository** → nombre `gestion-proyectos-utpl` → **Public** → *Create*.
2. **Add file → Upload files** → arrastre todo el contenido de esta carpeta (no la carpeta en sí: `index.html` debe quedar en la raíz) → *Commit changes*.
3. **Settings → Pages** → *Source*: `Deploy from a branch` → *Branch*: `main` / `(root)` → *Save*.
4. En 1–2 minutos aparece la dirección: `https://<su-usuario>.github.io/gestion-proyectos-utpl/`.
5. Ábrala **desde otro dispositivo** (teléfono con datos móviles) y compruebe logo, enlaces y la sección «Lo próximo». Guarde una captura.

> El repositorio es público: todo lo que entra en él, incluido el historial, es público. No suba listas de estudiantes, calificaciones, correos personales ni el PDF con derechos de autor.

## Enlazar desde el aula virtual (EVA, Moodle)

- **Recurso URL** en la sección general del curso: «Sílabo interactivo y cronograma», apuntando a la dirección de Pages.
- El plan docente oficial, las entregas y las calificaciones siguen en el EVA.
- Cargue las fechas importantes también en el **Calendario** del EVA para que los recordatorios lleguen por el canal institucional.

## Límites declarados

La lista de tareas guarda marcas solo en el navegador del estudiante: no la ve el docente, no es una entrega ni un registro académico, y se pierde al borrar datos o cambiar de dispositivo. Autenticación, entregas y calificaciones requieren los sistemas institucionales.
